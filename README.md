# quyundongyuanx

本仓库按产品线和端类型归档原型文件。

## 目录结构

```text
趣运动/
馆掌/
  PC/
    V1.0/
    V2.15/
  移动端/
  教练端/
    V1.0/
```

## 当前版本

- 馆掌 / 教练端 / V1.0：根据《馆掌——教练端 V1.0》整理的移动端前端交互原型。
- 馆掌 / PC / V1.0：保留原有馆掌 PC/admin 页面文件。
- 馆掌 / PC / V2.15：根据 V2.15 培训后台需求整理的馆掌 PC 后台交互原型。

## 预览方式

教练端 V1.0：

```bash
cd "馆掌/教练端/V1.0"
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173/
```
