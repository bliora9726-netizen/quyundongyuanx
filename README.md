# quyundongyuanx

## 馆掌—教练端

根据《馆掌——教练端 V1.0》整理的移动端前端交互原型。

### 页面范围

- 场地：场地库存、约课确认、约课结果联动课程
- 学员：学员列表、搜索筛选、学员详情、课程卡、上课记录、请假记录
- 续报：选择课程卡、生成支付二维码、订单支付、超期、作废、重新发起
- 训练：课程日历、今日课程、课程详情、签到、批量签到、学员请假、移除、完成课程、撤回课程
- 我的：教练主页、门店切换、我的上课记录、我的学员订单、操作日志

### 运行预览

```text
http://localhost:5173/
```

也可以直接打开 `index.html` 预览。若需要启动本地服务：

```bash
python3 -m http.server 5173
```
